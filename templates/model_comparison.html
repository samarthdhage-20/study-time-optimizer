Why Does the Prototype Use XGBoost?

Best on Current Simulated Data ≠ Automatically Best for Future Real-World Data

Linear Regression is the best-performing model in this specific simulated experiment according to the defined ranking criteria. The synthetic target was generated using a predominantly linear relationship between difficulty, importance, current performance, study hours, and academic performance score. Linear Regression is therefore naturally well suited to this dataset.

XGBoost achieved very similar performance, with only a small difference in R², RMSE, and MAE. It is retained as the prototype's experimental predictive model because future real-world academic data may contain nonlinear relationships, diminishing returns from additional study hours, and interactions between difficulty, performance, importance, and study behavior. Future features could include attendance, previous scores, revision frequency, assignments, mock tests, and topic-level performance.

This is an architectural and future-scalability decision, not a claim that XGBoost won the current experiment.
